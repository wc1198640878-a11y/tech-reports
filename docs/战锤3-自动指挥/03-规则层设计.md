# v2 规则层设计（最小伤亡导向）

## 1. 总体架构：分层指挥

```
层0 原生AI打底：v1 已实现——全军移交给 script_ai_planner，半自主作战
层1 规则覆盖层（v2 新增）：每 2s 轮询战场状态，对特定单位做"收编-直控-交还"
```

核心原则：**只在收益明确的时机干预**，其余时间让原生 AI 发挥。干预 = 把单位从 planner 移除（remove_sunits）→ 用 unitcontroller 下达精确指令 → 完成后再 add_sunits 交还。每次干预要设置"冷却"，防止脚本与原生 AI 抢控制权造成单位抽搐。

## 2. 分队模型（Deployed 时建立，用 unit:is_* 系列函数分类）

| 组 | 判定 | 职责 |
|----|------|------|
| line | is_infantry 且非远程 | 正面接战线 |
| anti_cav | is_anti_cavalry_infantry / is_pikemen | 两翼反骑 |
| ranged | 步兵远程 | 输出主力，受保护 |
| artillery | is_artillery / is_fixed_artillery | 高价值输出，绝不进近战 |
| cav | is_cavalry / is_chariot / is_war_beasts | 机动组：包抄/救火/追溃 |
| flyers | can_fly | 偷后排/支援 |
| lords | is_commanding_unit 或英雄 | 光环走位 |
| reserve | line 中按 strategic_value 排名的次强 15% | 轮换与救线 |

## 3. 野战决策规则（每 tick）

### 3.1 接战阶段（双方距离 > 150m）
- 保持现有阵型（planner 的 attack_force 会缓慢推进）
- 规则层不动，除非：
  - 敌方炮兵持续射击而我方 ranged 未还击 → 引导 ranged 目标
  - 敌方单骑/空军绕后 → 指派最近 cav/flyers 拦截

### 3.2 接战阶段（< 150m 或已有单位接战）
- **高价值目标聚焦**：敌方领主/法师/炮兵标记为 HV 目标，2-3 队 ranged 集中射击
- **骑兵侧翼**：cav 组收编直控 → goto 到敌方远程/炮兵侧后 → attack → 接战 8s 后 halt + goto 脱战 → 再次冲锋（cycle charge）
- **受损轮换**：line 单位 unary_hitpoints < 0.5 且士气 wavering → 后撤 30m 到 reserve 线，reserve 补位
- **救火**：我方 ranged 被敌方 cav 近身 → 最近 line 单位救援

### 3.3 决胜阶段（敌方 balance of power 崩盘）
- 有限追击：只派 cav 追溃，line 保持阵型（防止被敌方回马枪）

## 4. 攻城战规则（攻/守分开）

### 4.1 攻方
- 层0 全托管（v1），原生攻城 AI 负责破城与推进
- 规则层只做：
  - 炮兵目标引导（城门 > 墙段 > 塔）
  - 占领点优先级：主力占最近胜利点
  - 受损单位后撤到安全区（城墙火力外）

### 4.2 守方
- 层0 全托管，原生 AI 守墙
- 规则层只做：
  - 城墙单位受损轮换（把预备队送上墙）
  - 城门被破后，line 在门口/街口列阵（关键堵口点 defend）

## 5. 待定难题（迭代中解决）

1. 骑兵 cycle charge 的精确控制：planner 托管下单位会自行追击，收编后如何稳定"冲-脱-冲"循环（参考 mod 的 chasing 库有成熟实现，等分析报告）
2. 追击控制：原生 AI 的追溃倾向 vs 最小伤亡目标（追溃收益：歼灭=战后损失更小；风险：被拖散。需实测权衡）
3. 法术时机：法师的 perform_special_ability 调用需要技能 key，需查 unit_special_abilities 表；先让原生 AI 放法术，v3 再接管
4. 与原生 AI 的控制权切换抖动：remove/add_sunits 的副作用（参考 mod 的 ensure_units_are_released 补丁）

## 6. 参数化

所有阈值（距离/血量/冷却/追击限制）集中到 CONFIG 表，注释标默认值与理由，方便实测调参。

## 7. 复盘机制

- 每 10s 输出状态快照：各组数量/平均血量/敌军剩余/balance of power
- 战斗结束输出总伤亡统计
- 用日志对比同阵容手动 vs 自动的战损，指导调参
