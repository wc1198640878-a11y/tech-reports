# WH3 自动指挥 Mod（自用）

《战锤3：全面战争》单机战斗内全自动指挥 mod：进战斗即接管玩家全军，由"原生战斗 AI 打底 + 自写 Lua 战术规则层"指挥，目标是以最小伤亡打赢。

## 快速使用

1. `build\build.ps1` 一键构建（自动跑全部检查）并安装到游戏 data 目录
2. 游戏目录 `data\script\enable_console_logging` 已由构建脚本创建 → 战斗日志落到游戏根目录 `script_log_*.txt`
3. 无需任何游戏内操作：进战斗（Deployed 阶段）自动全托管
4. `tools\analyze_stats.ps1` 拉取全部战斗的战损对照表

## 架构

```
src/script/battle/mod/wh3_auto_commander.lua   主脚本（自动加载）
  ├─ 释放盾补丁：压制 CA wrapper 的 ensure_units_are_released（防全军僵死）
  ├─ 收编管道：全军移交 script_ai_planner（pending 延迟 + 所有权镜像 + 诊断）
  ├─ 军级目标：野战分阶段（列阵推进→距离合适接战）；攻城 SIEGE_SAFE（只移交不下目标）
  └─ 战损统计 STATS / 胜利追击收集
src/script/wh3ac_lib/ac_tactics.lua           规则层（require 加载）
  ├─ 预备队轮换：最弱 15% 殿后，血量 <25% 换防（投入门槛 60%，残血不返场）
  ├─ 骑兵：两翼协同推进→接战才冲锋→8秒脱离循环→后排威胁拦截
  ├─ 飞行纪律：扣住→战线建立才投入→低血拉回（带冷却）
  ├─ 炮兵：反炮兵→打敌方远程→高价值目标；被近身转移阵地
  ├─ 两翼包夹：最快线兵绕敌侧翼（领英雄/残血排除；追击带绳约束）
  ├─ 攻城：野战规则门控禁用；挂机轻推（闲置 30s 就近攻击）
  └─ 胜利追击：就近追歼溃军（防重复下令）
```

## 构建流水线（五道门禁）

```
① 语法检查（luaparse）→ ② 释放盾作用域 lint → ③ 函数定义顺序 lint → ④ 战术单元测试（51 断言）→ ⑤ 主脚本集成测试（7 断言）→ 打包安装
```

离线测试框架：fengari（纯 JS Lua VM）+ 手写游戏 API 桩（`test/test_tactics.lua`、`test/test_main.lua`）。

## 实战踩坑记录（血泪教训）

| 坑 | 后果 | 防线 |
|---|---|---|
| mod 脚本调用 `load_script_libraries()` | 二次构造 battle_manager → all_scriptunits 永久为空 → 每个单位刷 CA 警告 | 不要调用；用默认战斗脚本已建好的 bm |
| `local current_phase` 声明在补丁函数之后 | 释放盾闭包绑到全局 nil → 盾失效 → 30 秒后全军控制权还给玩家 | lint_main.js（声明顺序断言） |
| `local function` 定义在使用它的函数之后 | 同名调用解析到全局 → 运行时 nil 崩溃 | lint_order.js（AST 定义顺序检查） |
| require 不返回表（模块无 return） | require 返回 true → 主脚本拿到布尔 → 全部规则失效 | 模块 return 表 + 回归断言 |
| CA wrapper 命令（attack_force/move_to_position）内部调 ensure_units_are_released | 玩家军队控制权被还回玩家 → 全军僵死（PATCH 9.4 同款） | 释放盾（Deployed 全程压制） |
| increment_formation_width 在 planner 托管下无效 | 宽度拉宽不生效（原生 AI 阵型宽度覆盖） | 已证伪移除；需线兵全手动控制才可实现 |
| 攻城战下野战军级目标（attack_force） | 与原生攻城 AI 冲突 → 动停震荡、零击杀 | SIEGE_SAFE + 攻城轻推 |
